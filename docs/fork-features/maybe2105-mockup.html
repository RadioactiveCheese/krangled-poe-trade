MOCKUP ONLY. Not a working feature. This is based on the maybe2105 fork's "automatic orb usage". That fork sends many crafting clicks per hotkey press with humanised mouse movement, which breaks GGG's third-party tool policy (one server action per user input, no crafting macros). This mockup keeps only a read-only idea: the user lists target mods, and the overlay says whether the item they just checked has hit. It never clicks or sends input to the game, and it has no start or run control.
